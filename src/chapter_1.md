# An Intro to XSS

## Building the website

We are going to be building a website using HTML, python and the flask framework

### Step 1

Create a new folder for your website in a folder (directory) that makes sense.


### Step 2

Set up a python virtual environment:

Run the command to create your environment:
```command prompt
python -m venv xss-environment
```
Activate the environment run only one of the below:
macOS/Linux:
```
source xss-environment/bin/activate
```
Windows (command prompt):
```
xss-environment\Scripts\activate.bat
```
Windows (powershell):
```
.\xss-environment\Scripts\Activate.ps1
```

Install Flask in the virtual environment:
```
pip install flask
```
